# Project documentation

| File | What it is |
|---|---|
| `PHASE1-PLAN.md` | Phase 1 execution plan: draft aim and objectives, week-by-week schedule, marking scheme, admin checklist |
| `PROJECT-LOG.txt` | Full project snapshot — report status, cited papers, tech stack, every feature, migrations, what remains |
| `CHANGELOG.txt` | Dated record of all work, newest first |
| `supervisor-meeting-logs.md` | Six meeting logs drafted from the project record — items for discussion, record of discussion, action list. Check dates and content before submitting |
| `supervisor-meeting-notes.txt` | Talking points: project pitch, the three AI layers, literature map, demo script |
| `research-papers.md` | All 11 cited papers: verification against Crossref/publisher, what each one is, how it's used, where my system goes further |
| `booking-systems-landscape.md` | Every booking product universities run, by market segment, plus what Monash Malaysia and Sunway actually operate |
| `systems-to-try-links.txt` | Live booking pages and vendor demos you can open yourself, with what to look for on each |
| `screenshot-capture-guide.txt` | Step by step for the eight screenshots the report needs, with exact filenames to save them as |
| `competitive-analysis.md` | LibCal, 25Live, EMS, Skedda, MIDAS, Fusion — honest test of the three gap claims, prepared viva answers |
| `ui-design.md` | Design system: brand, colour tokens, typography, layout, animations |
| `meeting.txt` | Personal meeting notes |
| `diagrams/` | System diagrams (PNG for Word, SVG for scaling) |
