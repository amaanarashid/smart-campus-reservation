--------------------------------------------------------------------------
 IF THEY ASK
--------------------------------------------------------------------------
"Is the 79.6% real?"   It is from a simulation of four student types. Real
                       acceptance is measured in the Phase 2 user study.
"Can two people book the same slot at once?"   No - PostgreSQL's exclusion
                       constraint rejects the second. The formal concurrent
                       test is in the evaluation plan.
"Are all rules in the database?"   Not yet. No-overlap is; opening hours,
                       length etc. are checked by the app today and move
                       into the database in the hardening step.
"Why Wokwi, not real hardware?"   Same ESP32 code would run on a real board;
                       simulation was approved by the supervisor and lets
                       anyone reproduce the demo.
